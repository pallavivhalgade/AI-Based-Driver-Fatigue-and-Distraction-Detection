# Dataset

This folder contains instructions for the driver fatigue detection dataset.

## Dataset Classes

Typical classes:

- open eyes
- closed eyes
- yawn
- no yawn

## Usage

1. Download or prepare the dataset locally.
2. Keep training and testing data separated.
3. Do not commit large datasets to GitHub.

## Training Flow

Dataset -> Preprocessing -> Model Training -> Evaluation -> TensorFlow Lite Conversion
